# Snake-Ladder-Game-GUI-
# 🎮 Slide & Climb

A GUI-based Snake & Ladder game built with Python and PyQt6.

## 🎯 Game Modes
- Player vs Bot
- Two Player

## ✨ Features
- Interactive game board
- Dice rolling
- Snakes and ladders
- Background music and sound effects
- Winner screen
- Rematch option
- Menu and Exit options

## 🛠️ Technologies
- Python
- PyQt6

## ▶️ Run the Game

```bash
python main.py
